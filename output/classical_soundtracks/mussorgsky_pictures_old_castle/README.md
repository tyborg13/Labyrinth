# Pictures at an Exhibition - The Old Castle

This workspace contains the first non-overwriting Escape the Umbra audition of Mussorgsky's `Il vecchio castello`.

- `source/` preserves the public-domain 1886 first-edition piano score byte-for-byte.
- `scripts/build_arrangement.py` reproducibly writes the score-derived normalized reduction and the v01 arrangement MIDI.
- `normalized/` contains the complete selected source reduction as MusicXML/MIDI plus its separate piano part.
- `versions/v01/` contains the independently named MIDI, Ogg/FLAC previews, render report, verification report, and complete arrangement notes.

This is an audition package only. It is not approved or wired into game music routes.
