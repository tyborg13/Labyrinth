# Original combat audition provenance

Iron Procession, Thorns in the Dark and The Hollow Gate were authored by Codex
as explicit symbolic note sequences, harmonies and arrangements for Escape the
Umbra at the project owner's request. They are new compositions, not remixes of
the first three auditions or transcriptions of identified existing works. Their
source of truth is `scripts/compose.py`; complete note events are retained in the
expanded JSON scores and MIDI files.

Classification: `original_authored_symbolic_composition`. No historical
public-domain source or external transcription license is asserted. No external
score, MIDI, audio recording, SoundFont, sample pack, console ROM/rip, or
audio-generation model supplied musical or instrumental input.

The strings use the existing project-generated `hollow_viola_c3.wav` and
`grave_cello_c2.wav` from `classical_dark_fantasy_v1`. The original bank manifest
records their mathematical synthesis and hashes. The other instruments use the
reviewed local synthesis equations and seeded noise from the prior audition
builder. The set reuses the v02 phrase renderer, circular filters and effects.

The exact source/dependency hashes and toolchain versions are frozen in
`SOURCES.json`; per-track render reports freeze the score/MIDI/audio hashes.
No claim of exhaustive melodic novelty screening or legal exclusivity is made.

Status: awaiting user audition. These are standalone candidates; the user has
not selected a production route for them. The first audition set and its two
versions remain unchanged and verifiable.
