# Provenance

This is a new arrangement of the project's original Codex-authored Thorns in the
Dark, requested by the project owner after the Ashen Pursuit and Iron Procession
string revisions. The immutable parent score is
`combat_set_02/versions/v01/02_thorns_in_the_dark/score.json`.

The two new supporting string parts are explicit authored note sequences.
Instrument input consists only of the prior local mathematical synthesis and
the project's generated canonical viola/cello samples. The unchanged bowed-string
synth uses harmonics and deterministically seeded noise. No external recordings,
scores, MIDI files, SoundFonts, sample packs, ROMs or model-generated audio were
used. Canonical assets and all previous auditions remain unchanged.

Classification: `original_authored_symbolic_composition`. No historical composer,
public-domain transcription, exhaustive novelty or exclusivity claim is made.
Source and dependency hashes are frozen in SOURCES.json, and delivered artifact
hashes are in render.json. Status: awaiting user audition; no production routing
has changed.
