# Provenance

These are new arrangements of the project's original Codex-authored Ashen Pursuit
and Iron Procession, made at the project owner's request. Their parent symbolic
scores are preserved and hash-locked. All new second-violin and viola notes are
explicitly authored in `scripts/build_strings.py`.

The new string instrument in `scripts/bowed_strings.py` uses mathematical additive
synthesis and deterministically seeded noise. No external recordings, scores,
MIDI files, SoundFonts, sample packs, ROM data or audio-generation models supplied
musical or instrumental input. Existing bass, pad, pluck and percussion synthesis
is reused; the pad still uses the project's mathematical canonical viola sample.
The canonical bank and previous renderers are unchanged. This local renderer is
versioned with the new audition package rather than replacing that bank.

Classification: `original_authored_symbolic_composition`. No public-domain
transcription or historical composer attribution is asserted. Source/toolchain
hashes are in SOURCES.json; each render report inventories delivered artifact
hashes. No exhaustive novelty or exclusivity claim is made.

Status: awaiting user audition. No production music route is changed.
