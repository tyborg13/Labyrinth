# Whole-run drivers (copies)

Durable copies of the real-HP whole-run drivers that perf units reuse: seeds 83 and 84217, three sections, normal max HP. They were originally perf-55/57's, and these copies come from perf-65's tools folder. GDScript files carry a `.txt` suffix so Godot never imports them from this checkout. Copy them into a unit's `/private/tmp/labyrinth_codex/<unit>/tools/` folder and drop the suffix.
