# GPU census (copies)

These are sd-10's per-screen GPU census tools, as copied forward by sd-11 and sd-12: Steam Deck settings 1280x800 / 115%, Edge smoothing Off, cel look. Run with `--rendering-driver vulkan`. Godot 4.6.1's Metal backend zero-fills GPU timestamps; draw-call counters work on either driver. GDScript files carry a `.txt` suffix so Godot never imports them from this checkout.
