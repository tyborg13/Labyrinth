## Change
1. **A Blender-native spec** on the CC0 humanoid armature in the 3/4 facing, with the facing check passing.
2. **Proportions, not silhouette.** The pose changes, so the fit gate measures proportions against the approved
   front, from feet to helm top: total height equal (±4%); helm, torso, pelvis-to-knee and knee-to-sole heights each
   within ±8%; shoulder width within ±10%. Report a table of every measure.
3. **Shoulder rule** (spec §3): shoulders level in 3D; in the front `joints_px.json` the far shoulder sits
   0.15 × |x_near − x_far| above the near one, ±10 px. The **true 180° rear** (mq-06), both feet planted: never a
   mirror, so the chain hand is on the screen-right side in the rear.
4. **Delivery in the curated format** (as mq-14):
   - `delivery/` with clays, part maps, solos, `joints_px.json`, manifests and the proportion overlay;
   - `COMMIT_MANIFEST.txt`, ≤ 6 MB;
   - `discarded_proof_sha256.json`;
   - a fresh regeneration that matches.
5. **Gates:** determinism, cache replay, ownership, the hash-bound delivery validator, and mutations that fail when
   each guard is removed. Proof that runs in a fresh checkout, using LF line endings.
6. **Report each view's native head-to-sole height.** The rear must stay within ±3% of the front, which the Lancer's
   maquette did not. If the true turn makes that impossible, report why in numbers.
