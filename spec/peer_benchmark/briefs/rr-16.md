## Change
Each fix gets a regression test that fails before the fix and passes after it.
1. **Optional painted-cap evidence** (`action_direction.py:105`). Samples without `parts` (the rr14 fixtures) must not
   crash. Painted-cap evidence is optional; skeletal direction evidence is required. The three rr14 checks pass.
2. **Mode metadata independent of overrides** (`compiler.py:80`). Emit the effective `forward_mode` metadata (body and
   world_step) for every clip and view whether or not the clip has `view_keys`. Regression: adding an empty
   `view_keys: {"rear": {}}` to a clip leaves both views' compiled output byte-identical (the review's front support
   foot moved (20,30) → (20,31)). If this changes the Thrall's front jab or tether output, report the changed frames
   and pixels.
3. **Reach minimum between samples** (`reach.py`). Partition each clip at its key phases. Within each interval, bound
   the minimum target distance between consecutive samples: if the straight segment between two sampled target
   positions (in the first bone's animated frame) comes closer to the chain root than the allowed minimum, bisect that
   interval to 1e-6 phase and report the true minimum and its phase. Regression: the review's short dip (segment
   lengths 40/20, target x −50 → +50 between phases .5001 and .5009) fails with a minimum near 0 px. The current
   Thrall data still passes with the same documented overreach list.
4. **Direction gate needs coverage** (`action_direction.py:114`). Each figure's case data lists the clips that must
   point toward the facing (for the Thrall: `jab` and `tether`; if the Seer runs this gate, list its clips the same
   way, otherwise leave it out). Every listed clip
   must produce at least one positive check in every view; zero checks fail with a named error. Regression: the
   review's zeroed action-forward channels now fail in both views. Mutation: removing the coverage requirement is
   caught.
5. **Exceptions match the exact pocket** (`gate_exceptions.json` and its reader). An exception names the frame, the
   rule, and the approved pocket's mask: its pixel set (or a bounding box plus pixel count) taken from the current
   capture. Only holes matching that pocket are excused; any other hole in the same frame fails. Regression: the
   review's extra-hole inputs (counts [2,50] at front jab 22, [7,50] at front death 31) now fail.
6. **rr07 production test** (`tests/test_rr07_production.py:29`). Route the Thrall through the rr11 probe and the
   humanoid contract, not the obsolete probe and six-pose idle contract. Remove or retarget only the Thrall's rr07
   assertions; the other figures' rr07 assertions stay as they are.
7. **Sidecars.** Run the headless import through the task runner and leave every new `.import` and `.uid` sidecar
   for resources this range added, so `tests/test_godot_sidecars.py` passes. Exclude nothing.
