# tt-02 — One sentence per card panel (owner request, 2026-10-25; continues tt-01)

## Header
- Owner: card tooltips must be "a single straightforward sentence", short, concise and accurate. Rule details belong
  in the Grimoire. tt-01 rewrote the glossary, but about 120 distinct card panels never read the glossary: their text
  is built in code (mostly `scripts/action_icon_library.gd`, through `token_for(..., tooltip_override)` and
  `tooltip_entries_for_rows`). Many are two or three sentences; some repeat a sub-heading inside the body
  ("Area pattern\nRed tiles are hit."); some render a whole sentence as the panel title with an empty body
  (area Push/Pull, "Light radius in tiles."); a Cleanse card shows the same sentence four times.
- Director copy, protected, import byte for byte: `spec/peer_benchmark/staged/tt-02/card_panels.json`.
  - `rules` R1–R7: the shape every panel must have.
  - `rows`: every rewrite (`text`), or `text: null` = show the glossary sentence for that term; `grimoire` = detail
    that must survive in that term's Grimoire entry.
  - `glossary_edits`: three tt-01 glossary definitions that were still two sentences.
- Director tool: `spec/peer_benchmark/director_tools/card_tooltip_dump.gd` dumps every card's focus stack (title,
  body) as JSON (`DUMP_PATH=... godot --headless --script ...`). Base dump (309 cards, 1,017 panels):
  `spec/peer_benchmark/staged/tt-02/base_panels.json`.
- Base `codex/peer-benchmark` (integration, green, tt-01 merged). Risk tier: standard. Owned:
  - `scripts/action_icon_library.gd` card-panel text and `tooltip_entries_for_rows` assembly;
  - other scripts that produce card focus panel text (find them with the dump);
  - `data/glossary.json` (the three `glossary_edits` only), `data/grimoire.json`;
  - new `data/card_panel_text.json`;
  - tests that pin the changed strings.
  - New headless programs: append them last in `tests/headless_test_programs.json` and add the matching
    `POST_SNARE_PROGRAMS` line.

## Change
1. **Data, not code.** Every card-specific panel sentence (the rewritten rows and the already-good ones listed under
   `unchanged`) lives in `data/card_panel_text.json`: id → template with named placeholders (`{n}`, `{r}`, ...),
   loaded once and cached. `action_icon_library.gd` looks sentences up by id instead of holding English literals.
   Future wording changes must be data edits only.
2. **Apply the copy** from `rows` exactly, including titles. Where `text` is null, the panel shows its glossary
   sentence (R2: never both).
3. **Apply R3–R7** in the stack assembly: ground panels drop placement lines (except `ice_to_electrified`), no
   sentence twice per stack (R4 rows), Cleanse hides the listed status panels (R5), titles are term names (R6),
   one panel per term unless the texts differ (R7).
4. **Glossary edits**: apply `glossary_edits` and update `spec/peer_benchmark/staged/tt-01`'s pins in the tests (the
   tt-01 copy file itself stays as it is; the tt-01 test should read the post-tt-02 expectation for these three ids
   from `card_panels.json`).
5. **Grimoire**: for every non-null `grimoire`, the named entry must state that fact. Append a paragraph if no
   existing paragraph already says it (tt-01 already appended many old definitions; don't duplicate). Report the
   count appended.
6. **Enemy intent and board tooltips are out of scope**: only card focus stacks (hand, rewards, shop, deck viewer,
   opening boons; anything that calls `tooltip_entries_for_rows` for a card).

## Tests (headless)
- Promote the dump into a test over every card (base and upgraded definitions) that asserts R1 (no `\n` in a body
  outside the `Modified by:` block, exactly one sentence-ending mark, ≤ 16 words), R4, R5, R6 (title ≤ 4 words, no
  final period), R7, and that no body is empty.
- Exact-text checks for every row (one representative card per row id; name it).
- Grimoire checks for every non-null `grimoire` fact.
- Mutation replay: restoring any old two-sentence string, re-adding a placement line, or re-adding a Cleanse status
  panel must fail the test.

## Proof
- New dump of every card's stack: `proof/tt-02/after_panels.json`, plus a summary of panels per card and
  words per stack, before vs after.
- Real renderer, 1920×1080, UI scale 100%: hover captures before and after for **Royal Bramble** (tallest, 8 panels),
  **Borrowed Spark**, **Lantern Shot**, the Cleanse card, the Meteorfall card, an area-Push card and the
  Swap Illusion card. Report each stack's height in px. List the windowed commands; the director runs and judges them.
- Focused only: the new test, the tt-01 tests, glossary, Grimoire, the UI identity lint and the icon identity policy.

## Out of scope
- Panel styling, widths and fonts; card faces; enemy intent and board tooltips; skill text; battlefield-rule lines.
