## Change
1. **Pure-Python geometry, one source of truth.** Move primitive mesh generation into a NumPy module
   (`maquettes/geometry.py`) that builds triangle meshes for every primitive from spec.json. `humanoid.py` (Blender)
   imports those meshes for rendering instead of building its own, so what you fit is exactly what Blender renders.
   Existing specs (gaoler, lancer r1, shrike, wisp, bloomer) must keep rendering equivalent silhouettes: per-part
   mask IoU ≥ 0.98 vs their committed renders (report per spec; the director runs Blender).
2. **Silhouette rasteriser** in NumPy for the same orthographic board camera (az 45°, el 30°, `ortho_scale`, target,
   1024²) with per-part masks and joint projection matching `joints_px.json` within 1 px. This lets you iterate without
   Blender.
3. **Sculpted primitives** (all optional, back-compatible):
   - `limb`: capsule with a radius profile `[r_start, r_mid, r_end]` + `mid_at` (0–1) for calves/thighs/forearms.
   - `torso`: lofted superellipse sections, e.g. `sections: [{z, width, depth, round}]` for chest > waist < hips
     (V-taper), with `lean`.
   - `shell`: partial ellipsoid shell (pauldrons, helms, hoods) with `cut` angles so it is a cap, not a full sphere.
   - `cloak`: draped cloth from anchor points (shoulders/neck) to a hem: `length`, `hem_width`, `flare`, `wrap`
     (radians around the body), `folds` (count, depth), `rag` (notch count, depth, seed), `thick`.
   - `smooth` on a part: weld that part's primitives (voxel remesh at `voxel` size) + smooth normals, so joints blend.
4. **Fit tool** `tools/maquette_fit.py`:
   - `measure`: the source art (green-keyed PNG) and the rasterised maquette front silhouette, both normalised to
     figure height (top of head/hood → lowest sole pixel) and aligned on the ground-contact centroid. Report:
     silhouette IoU; width profile in 24 horizontal bands with per-band relative error; landmark height error for
     `fit.landmarks` (director-measured y-fractions of the source, e.g. shoulder, waist, hip, knee, ankle) against the
     spec's joints. Writes `fit_report.json` and `fit_overlay.png` (source cyan, maquette magenta, overlap white, band
     errors charted).
   - `fit`: deterministic adjustment of the spec toward the source — rescale joint heights piecewise between
     landmarks to hit the landmark fractions, then scale shape widths per band by the source/maquette width ratio
     (clamped 0.6–1.6, per part, preserving the part's shape type). Writes `spec_fit.json`; never overwrites spec.json.
   - Gate (spec `fit.gate`, defaults): IoU ≥ 0.80, median band width error ≤ 12 %, max band error ≤ 30 % excluding
     bands that only hold the weapon, landmark error ≤ 0.03 of height.
5. **Lancer r2** `spec/art_identity/maquettes/frostglass_lancer/spec_r2.json`, built with the new primitives and
   passing the gate against `03_identity_lancer_current.png`. Director's proportion intent (from the source): slender
   build; small pointed hood with a narrow face slit; shoulders ≈ 1.6 head-widths; pauldrons modest shells, not
   spheres; narrow waist under a belt; legs ≈ 45 % of height with knee guards; ragged cloak from both shoulders,
   wrapping the sides and flaring to ≈ 1.6× shoulder width at the hem, hem notched; spear held out to the figure's
   right as in the source; slight forward lean and weight on the rear leg. Same part labels as r1 (cutout ownership
   must stay possible). If the gate cannot be met with these intents, report the conflicting bands rather than
   breaking an intent.
