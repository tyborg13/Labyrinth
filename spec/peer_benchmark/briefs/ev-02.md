# ev-02 — Illustrated event screen, omen HUD, event/omen art processing

## Header
- Goal: events open a full-screen illustrated panel (Slay-the-Spire grammar in Umbra's materials): painting on the left,
  title, body and 2–3 choice plates on the right with exact colour-coded outcome lines; a result page; and active
  omens show as wax-seal badges in the HUD with fights left.
- Base: `codex/peer-benchmark` after ev-01 merges (the director gives the base commit). Uses ev-01's EventRules /
  OmenRules API (`choice_effect_lines`, `choice_available`, `choice_block_reason`, event_state pages, outcomes,
  `OmenRules.active`).
- Approved mockup: `output/peer-benchmark-2026-10-12/mockups/event_choices.png` (+ `event_result.png`,
  `event_disabled.png`), source `mockups/event_screen.html` + `render_event.py` — the CSS there is the visual spec.
- Owned files: new `scripts/event_view.gd` (+ small helpers if needed under `scripts/event_view_*.gd`), new
  `scripts/omen_badges.gd`, new `tools/process_event_art.py` + `tests/test_process_event_art.py`, new
  `assets/art/events/*.png`, new `assets/art/icons/omens/*.png`, new `spec/assets/events/README.md` + hashes, new
  `tests/event_view_probe.gd`, new `tests/suites/event_view_suite.gd` + `tests/event_view_test.gd`;
  modify `scripts/section_map_panel.gd` (remove the stopgap event panel and its refresh path),
  `scripts/run_scene.gd` (open/close the event view, omen badges in the header HUD; ≤ 60 lines), `scripts/ui_palette.gd`
  (event tone tokens), `spec/events.md` (presentation section), icon registry + `tests/test_icon_identity_policy.py`
  data if omen icons must be registered there (follow spec/icon_identity_policy.md).
- Rules: presentation only; Windows typed-array rule; the art files are processed from the approved raw images only;
  `TODO_DESIGN_<name>` for anything undecided.
- Contract: risk tier standard (broad UI). Acceptance: (1) event rooms open the illustrated view per mockup at
  1920×1080/100%; (2) all 27 events fit (no clipped text, no overflow) with every choice state; (3) mouse, keyboard
  (1–3, arrows, Enter) and controller paths; (4) result page and Continue; card choice follows when granted; (5) omen
  badges with counts and tooltips in room and combat HUD; (6) art provenance + hash test.

## Change (numbered, testable)
1. **Art processing** `tools/process_event_art.py`: event paintings → `assets/art/events/<id>.png` at 1152×768 (Lanczos,
   then PNG optimise; keep RGB, no alpha); omen icons → key #00FF00 (no fringe), trim to the seal's bbox, pad to square,
   resize to 96×96 → `assets/art/icons/omens/<id>.png`. Deterministic. README records prompt paths and raw + output
   sha256; a hash test asserts the outputs.
2. **EventView** (full-screen modal over the board; the map stays closed while it is open):
   - Scrim: board blurred/dimmed like other modal overlays (existing modal scrim), plus a radial darkening.
   - Panel: 1640×780 at (140,150) on 1920×1080, the existing major-dialog material (`ThemedPanelOrnament`, bold corner
     brackets, gilded hairline).
   - Art: the event painting in a 1062×728 rect at panel (26,26), cover-fit; its right 18% fades to the panel (alpha
     mask), top 7% and bottom 10% fade likewise; no frame on the art.
   - Right column at panel x=1060, width 540: eyebrow "EVENT" (eyebrow font, 15 px, letter-spacing 5, GOLD_DIM); title
     (UI font 44 px, GOLD_BRIGHT; shrink in 2 px steps to ≥ 34 px if it would wrap); gilded rule
     (`ui_gilded_rule.gd`); body (Text font 22 px, line height 1.42, TEXT); choices follow the body after 32 px.
   - Choice plate: the existing choice-plate drawing (`ui_surface_finish.gd` `_draw_choice`), width 548, padding
     13/18/13/58 px; key disc 26 px at left (GOLD_DIM ring, numeral 1–3 in GOLD); label UI font 24 px TEXT; effect lines
     Text font 19 px below the label, one row per effect line, coloured by tone: cost `#e07a6c`, gain `#e9cf8f`,
     bane `#c58cf0`, blessing `#f2d27a`, odds/neutral TEXT_2 `#b5a58a` (the "NN%:" prefix in TEXT_2, the rest in its
     tone). Add these as `UiPalette` tokens EVENT_COST/EVENT_GAIN/EVENT_BANE/EVENT_BLESSING.
   - Hover/focus: the choice plate's emphasis state (brightened gilding + soft ember glow, 22 px, 28%). Clears on exit.
   - Unavailable: plate at 50% opacity, label TEXT_2, the block reason below in Text 17 px italic TEXT_3; not
     activatable, still focusable (shows the reason).
   - Result page: the body is replaced by the result text (Text 22 px italic, `#d8c9a8`), then 30 px gap, then a quiet
     well listing the outcome rows (Text 19 px, toned), then a primary ember-bronze "Continue" button (existing
     VARIANT_SELECTED) anchored 40 px above the panel bottom on the right column.
   - Layout must fit every event: if the right column would overflow, reduce body to 20 px, then effect lines to 18 px;
     never clip. The probe asserts fit for all 27 × both pages.
3. **Motion.** Open: scrim fades 0.18 s; panel fades + rises 12 px over 0.22 s (ease-out); the painting fades in once
   the panel passes 80% opacity, then a slow 1.04→1.00 scale settle over 0.9 s. Page change: right column cross-fades
   0.18 s; outcome rows stagger 0.08 s. Reduced motion: fades only, no rise/zoom. Close: 0.16 s fade.
4. **Sound** (existing cues only): open = menu page open; choice = the existing button click; Continue = menu page close.
   No new stingers.
5. **Input.** Mouse; keys 1–3 choose; Up/Down move focus; Enter/controller A activates; Back/Escape does nothing on the
   choices page (events must be resolved) and activates Continue on the result page. Controller prompt bar names the
   focused choice. Initial focus: the first available choice.
6. **Omen badges.** In the header HUD (room and combat), after the relic badges, one badge per active omen: the 96 px
   icon drawn at 38×38 (same height as relic badges), a fights-left numeral bottom-right (UI font 15 px, TEXT on a
   16 px INK_0 disc with a 1 px border in GOLD for blessings / `#9a7cf0` UMBRA for banes). Tooltip (shared tooltip
   panel): "<Name>" title, "Blessing"/"Bane" eyebrow in the tone colour, description with inline icons, "N fights left".
   When an omen is gained, its badge pops (scale 1.25→1.0, 0.25 s); when it expires, it fades out 0.3 s.
7. **Result rows for omens and relics** may show the relic/omen icon at 20 px before the text.
8. **Spec.** spec/events.md "Presentation" section with the values above.
