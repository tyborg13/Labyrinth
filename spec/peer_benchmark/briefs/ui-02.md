2. **Near-palette literals** (not equal to any token): do NOT change them. List each (file:line, value, nearest token,

4. Pixel identity: a probe capturing the labyrinth map (with several node types and hover), the skill tree (with
   locked/unlocked/selected nodes) and the section map at 1920×1080, run before and after; the images must be identical.
