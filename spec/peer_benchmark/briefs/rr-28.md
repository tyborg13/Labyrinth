1. **Close every tear the way rr-27 closed the Thrall's front pockets.**
   - Use clip-scoped own-piece continuations: copy existing density-treated texels of the same piece under the joint,
     active only in the clips that need them (a `gait_continuations` recipe with a `clips` list).
   - Where one shared recipe covers several frames of a clip (the rear `mark` and `death` runs), use it.
   - No new paint, no skin-weight changes unless an attachment is the only fix, no motion changes.
   - If a tear can't be closed by own-piece texels, stop for that tear and report it with a crop. Don't exempt it.
2. **Density.**
   - If a recipe changes a shipped piece PNG, adopt it through `tools/process_board_density.py --adopt … --force-adopt`.
     rr-27 did this for the Thrall's rear leg.
   - Re-derive outputs with `--only <id>`. They must stay byte-identical except the declared texels.

   - Scope it the way int-04 scoped the tests: the Capacitor's own shadow records stay exact, and other figures are
     not policed.
