# qa-14 — Guard: Godot sidecars stay versioned

## Header
- **Why.** The repo policy (`.gitignore` comment) and Godot 4 keep `*.import` and `*.uid` sidecars under version
  control. Older assets were committed without them, so every worktree regenerated about 10,000 sidecars as untracked
  files, each with its own random UIDs. The director committed them all on integration (bf68dc2ce, 10,664 files).
  This unit makes that permanent with a guard.
- **Owner request (2026-10-19):** handle the import sidecar noise permanently.
- **Base:** `codex/peer-benchmark`. **Owned:** a new `tests/test_godot_sidecars.py`, `spec/development_workflow.md`
  (one short section), and `tools/output_gdignore.py` only if needed.

## Change
1. **Guard test** (`tests/test_godot_sidecars.py`, discovered by the Python suite), reading `git ls-files`:
   - every tracked file of an importable type has a tracked `<file>.import`. Take the importable extensions from the
     sidecars already in the repo, or Godot's importer list (png, jpg, jpeg, webp, svg, wav, ogg, mp3, ttf, otf, woff,
     woff2, glb, gltf, …). Exclude files under a `.gdignore`d folder;
   - every tracked `.gd`, `.gdshader` and `.gdshaderinc` outside `.gdignore`d folders has a tracked `<file>.uid`;
   - no tracked `.import` or `.uid` exists without its tracked source file (no stale sidecars);
   - failure messages list the exact missing or stale paths and say to run `godot --headless --import` and commit the
     sidecars.
   - Mutations: drop one tracked `.import`, one tracked `.uid`, and add one stale sidecar; each must fail.
2. **Docs:** add a short "Godot sidecars" section to `spec/development_workflow.md`: new assets and scripts are
   committed with their `.import`/`.uid`; run the headless import before committing; never `.gitignore` sidecars; scratch
   output folders use `tools/output_gdignore.py` so Godot doesn't import them.
3. If the test finds gaps on today's tree, list them in the result; don't change assets.

## Proof
Run the new test, `tests.test_test_registration_audit`, and the mutations. No full suites. No Godot changes beyond a
headless import if needed.
