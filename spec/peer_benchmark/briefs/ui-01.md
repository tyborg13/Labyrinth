# ui-01 — UI identity lint (ratchet) + review wiring

## Header
- Contract: `spec/ui_identity_gate.md` (read first) and `spec/ui_identity/judge_rubric.md` (director data, protected).
- Base: `codex/peer-benchmark` (director gives the commit). Owned files (new unless noted): `tools/ui_identity_lint.py`,
  `tests/test_ui_identity_lint.py`, `tests/fixtures/ui_identity/**`, `spec/ui_identity/baseline.json` (generated),
  `spec/ui_identity/exceptions.json` (empty list), `spec/ui_identity_gate.md` (append a "Commands" section only).
- Rules: tooling only — no game-script edits, no visual changes; Python 3.9 compatible, standard library only;
  deterministic output (sorted keys/paths); follow the style of `tests/test_icon_identity_policy.py` (unittest,
  `REPO_ROOT`, module-level allowlists with a reason comment each).

## Change
1. `tools/ui_identity_lint.py scan [--json]`: implement rules R1–R6 exactly as the spec's table, per file and rule,
   with file:line for every site. Parse GDScript tolerantly with regexes: ignore matches inside comments (`#…`) and
   string literals other than the `Color("…")` argument itself; multi-line calls count once at their first line.
   - R2 detail: `Color("#abc")`, `Color("abc")`, `Color("rrggbbaa")`, `Color(0.1, 0.2, 0.3[, a])`,
     `Color8(…)`, `Color.from_hsv/hsl(...)` with numeric literals all count; `Color(1, 1, 1, x)` / `Color(0, 0, 0, x)`
     with any alpha expression and `Color(<identifier>, x)` do not. Also report (separately, informational) literals
     whose hex equals a `scripts/ui_palette.gd` token value, with the token name.
   - R6 detail: integer literals < 14 used as the font-size argument of `draw_string`, `draw_multiline_string`,
     `add_theme_font_size_override`, or assigned to `font_size`/`*_font_size` variables.
2. `--write-baseline` (creates `spec/ui_identity/baseline.json` from the current tree; refuses if it exists unless
   `--force`), `--tighten` (lowers counts that dropped; never raises; removes zero entries), `check` (exit 1 on any
   count above baseline + exceptions, or a violation in a file absent from the baseline; prints the new sites and the
   helper to use per rule: R1 → `UiSkin` / `UiComponentSurface.draw_plate`; R2 → `Palette` token; R3 →
   `GildedFrame.draw_panel` or a painted frame; R4 → the painted frame overlay used by unit bars; R5 → `UiTypography`;
   R6 → the type scale in `ui_typography.gd`).
3. Generate and commit the baseline from the base commit.
4. `tests/test_ui_identity_lint.py`: unit tests per rule on fixtures (including comment/string exclusions and the
   neutral-modulate allowance), `check` passes on the committed tree, fails on a synthetic added violation (temp copy),
   `--tighten` never raises a count, and a policy test asserting AGENTS.md and `.codex/skills/create-labyrinth-ui/
   SKILL.md` cite `spec/ui_identity_gate.md` (the director adds those lines; the test documents the requirement).
