# rr-01 — Roster wave 1a: recolour the crawler rig to the new standard

## Header
- Owner (2026-10-13): phased roster upgrade, regulars first. Legacy audit (spec/peer_benchmark/staged/legacy_audit/):
  crawler fails only on palette — pale beige flesh, value 0.29 front / 0.32 rear vs ≤ 0.24 for the approved enemies.
- Director decision: a deterministic recolour in CIE Lab: L* × 0.76 and a*, b* × 0.85 on every opaque pixel; alpha and
  fully transparent pixels unchanged. Reference implementation of the colour conversion:
  `spec/art_identity/prototype/match_palette.py` (`to_lab` / `from_lab`; round with `np.rint`). Verified on the front
  rest: value 0.292 → 0.222, chroma 0.114 → 0.093.
- Base: `codex/peer-benchmark` at ade48025f. Owned files: every PNG under
  `assets/units/crawler_cutout/{front,rear}/` (parts and rests), the crawler static fallback
  (`assets/placeholders/units/crawler_anime_trial.png` and its idle sheet if present), the crawler turn-order portrait,
  board-density sources/outputs/rest records and shadow cache entries for the crawler only,
  `spec/art_identity/registry.json` (crawler legacy entries only), a new `tools/recolour_lab.py` (+ test), and
  `spec/art_identity/README.md` Commands. Do not change rig layouts, joints, motion or any other enemy.

## Change
1. `tools/recolour_lab.py --l-scale 0.76 --ab-scale 0.85 FILES...` (deterministic; refuses non-RGBA; writes in place
   only with `--in-place`; prints before/after value/chroma per file).
2. Apply it to the untouched density **sources** of the crawler's parts/rests (the board-density registry keeps
   untouched originals under `spec/assets/board_pixel_density/sources/`), then re-run the density pipeline for the
   crawler (process, native rest rebake, `--record-rests`, shadow cache, `--check`) so production files are derived as
   before. Recolour the portrait and static fallback directly.
3. Registry: the crawler's legacy entries get their new pixel digests plus `"post_steps": [{"step": "recolour_lab",
   "l_scale": 0.76, "ab_scale": 0.85, "reason": "legacy audit 2026-10-13: palette"}]`; `check` must accept a legacy
   entry whose digest changed only when such a recorded step reproduces it from the previous digest's source (or state
   the simplest sound alternative you chose).

## Proof
Tests (recolour tool, density, gate, crawler/cutout suites, full suite). Windowed: the bestiary lineup probe (list the
command); a before/after contact sheet of the crawler front/rear rests and portrait.
