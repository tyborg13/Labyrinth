## Hoarfrost Seer `hoarfrost_seer`
1. **Icefall mark** (`icefall_mark`, shape `line3_perpendicular`, range 5): marks the hero's tile and the two tiles
   beside it on the axis perpendicular to the seer→hero direction (for a diagonal direction use the row through the
   hero). Off-board/impassable tiles are skipped. Delayed marks, ice tint, Icefall icon, "5". Requires the hero within
   range 5; else the seer uses Rime Bolt or Withdraw.
2. **Icefall land** (forced next intent): each marked tile takes 5 ice damage (any unit) and gains an **Ice Pillar**
   unless a unit still stands there after the damage (then no pillar on that tile). Ice Pillar: impassable terrain for 3
   rounds (count down at the end of each enemy turn), blocks line of sight like other pillars; a unit pushed into a
   pillar takes 2 and the pillar shatters (removed). Draw: reuse the existing raised-terrain/pillar renderer with the ice
   biome's pillar art if the biome set has one (Iskaldra), else the existing rock pillar tinted `#9cc8e6` at 70%; list
   which you used. Landing animation: an icicle streak falling 0.18 s onto each tile, then a frost puff.
3. **Rime Bolt**: ranged 3 + Chilled (existing status), range 4. **Withdraw**: move away 2 + Block 4.

## Gale Herald `gale_herald`
4. **Call the Wind** (`call_wind`, rounds 2, push 1, `toward_hazard`, scan 3): pick one of the 4 board directions:
   the direction in which, starting from the hero, a hazard (wall/pillar/impassable, damaging surface, trap, or another
   unit) is closest within 3 tiles; ties → the direction pointing toward the herald; none within 3 → toward the herald.
   Store `wind = {direction, rounds_left: 2, source_id}`. At the end of each enemy turn while `rounds_left > 0`, push
   every unit 1 tile in that direction except bosses, guardians' leaders, constructs and units with `anchored`
   (the herald itself is anchored); order: the unit farthest downwind first; normal push/collision rules and damage;
   then `rounds_left -= 1`. The wind ends when the herald dies (immediately) or rounds run out. A new Call refreshes it.
5. Telegraph: while wind is active (and during the herald's Call intent preview, as a dashed preview), draw faint
   chevrons over every visible floor tile pointing downwind (white-blue `#cfe3f2` at 22% alpha, 2 per tile, drifting
   40 px/s, reduced motion: static), and for each unit that will be pushed, the existing push preview arrow and
   collision marker exactly as card pushes show them. Add a small HUD chip under the turn clock: wind icon + "Wind ·
   <rounds>" (TODO_DESIGN_ICON_wind until the icon lands) with tooltip "At the end of each enemy turn, everything not
   anchored is pushed 1 tile <direction>."
6. **Gust Bolt**: ranged 3 + push 1, range 4. **Still Air**: Block 5.
