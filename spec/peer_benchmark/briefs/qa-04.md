# qa-04 — Test noise from Godot imports under output/, and the stale en-05 sync test

## Header
- Every full Godot run imports PNG/OGG files under `output/` and leaves untracked `*.import` sidecars there (seen after
  every suite on 2026-10-13/15). `tests/test_chopin_death_music.py::test_v05_builder_proves_v04_remains_immutable` then
  fails because a sidecar appears in an immutable version folder. Several tests and probes legitimately load files
  from `res://output/...` (e.g. `res://output/contextual-animation-polish/...` cutout cases), so `output/` cannot simply be
  hidden from Godot.
- `tests/en05_integration_sync_test.gd` (not in the full suite) fails because `output/en05_integration_shadow_base.res` is
  missing, and its presentation-equality assertion is obsolete after art-04 (gust shrike).
- Base: `codex/peer-benchmark`. Owned files: `.gdignore` files under `output/` subfolders, `.gitignore`,
  `tests/test_chopin_death_music.py` / its builder only if needed, `tests/en05_integration_sync_test.gd`, the test
  runner docs if they enumerate tests.

## Change
1. Find every `res://output/...` path loaded by tests, probes and tools. Add `.gdignore` to every `output/` subfolder
   that nothing loads through `res://` (generated per subfolder from the scan, committed only where the folder is
   tracked; for untracked folders, write them via a small script `tools/output_gdignore.py` that the suite runner or
   developers can run, and document it). The folders that are loaded keep importing.
2. Make the Chopin immutability check ignore Godot `*.import` sidecars (they are not part of the artifact), with a
   regression test that an added `.import` sidecar does not fail it while any other added file still does.
3. `en05_integration_sync_test.gd`: either regenerate its missing fixture deterministically and update the obsolete
   gust shrike expectation to the art-04 presentation, or retire the test if its purpose (en-05's integration sync) is
   fully covered by the en05 suite — state which with evidence. Do not weaken other assertions.

## Proof
Full Python discovery and the full Godot suite run twice back-to-back in the worktree with no new untracked `.import`
files under ignored folders and no Chopin failure; the en-05 sync test passes (or is retired with reasoning).

## Out of scope
Deleting anything under `output/`, moving files used by tests.
