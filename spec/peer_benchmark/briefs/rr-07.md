     `*_solo_*.png`, `*_parts.png`, `*_clay.png` and `joints_px.json`, as the rig inputs.
   - If anything the rig needs is missing there, stop and report. Don't render.
2. **Rigs.** Build them the rr-04/rr-05 way:
   - ownership from the part renders;
   - hidden-material requests where parts overlap;
   - connected parts and seam underlays;
   - rest identity 0 px against the approved processed art, in both views.
   
   The approved paintings were registered to the maquette by the identity gate. If a part's painted pixels sit outside
   its label area, report it; never move paint.
3. **Feature masks** (rr-05 format). Each feature is owned by one part, includes a 1 px rim, and has its holes filled.

     - the collar's chain stub (front) is owned by `collar` (rear: occluded).
   
   Report each mask's pixel count with a zoomed outline crop. If a mask is ambiguous, stop with TODO_DESIGN.
4. **Production.** Replace both static board arts with the rigs and map intents exactly as each clip's `intents`

5. **Gates.** Apply the rr-04/rr-05 gates as they are, for both creatures:

   - production capture from real clip progression, with ≥ 6 changing frames per action including contact;
