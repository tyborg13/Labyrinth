## Change
1. **Bounded placement (director rule).** A unit's HUD group (bar + plates + pills, moved as one) stays with its
   owner. To clear fixed order discs, crests, intent lines and other groups, try in this order and take the first
   collision-free spot:
   a. the anchored spot;
   b. horizontal shifts in 4 px steps up to 24 px right, then up to 24 px left;
   c. one row up (bar height + 4 px), then one row down, each with the same horizontal shifts.
   A group never moves more than one row vertically or 24 px horizontally, never leaves the board area (the floor
   polygon's screen bounds plus a head-room band above it), and never moves onto reserved screen UI (hand, PASS,
   battlefield and objective panels, turn-order strip). There is no cascading search.
2. **Compact before overlapping.** If no bounded spot is free, the group drops the words from its pills (icon and
   count only, exactly like variant A's pills) and retries step 1. If it still collides, it takes the bounded spot
   with the least overlap area.
3. **Deterministic overlap order.** When groups still overlap, the group whose owner stands nearer the camera (larger
   floor screen y; ties by column) draws on top. The hovered or controller-focused unit's group draws above all.
   Tooltips and focus rects follow the drawn rects.
4. **Incremental movement.** Restore an incremental interpolation path: a moving unit re-places its own group and
   only the groups its old or new rect touches; everything else is reused. No full layout rebuild and no new
   deep-layout LRU entry per interpolation sample. Target: on the reviewer's matched 12-unit movement benchmark,
   submission p50 within 1.15× of base `codex/peer-benchmark` (reviewer measured 0.80 ms base, 3.55–3.82 ms now).
5. **Crest guard.** Add a fixture where both default threat-chip candidates collide with placed leader crests, so
   removing crest obstacles fails the suite (the reviewer's surviving mutation).
