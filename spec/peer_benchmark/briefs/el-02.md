# el-02 — Battlefield rules: Warband and Snare retrofit, ordinary enemies on the same pieces, keyword retirement

## Header
- Builds on el-01 (merged): `scripts/battlefield_rules/`, `data/battlefield_rules.json`. Binding design:
  `spec/peer_benchmark/element_rules/design.md` §3 and §4 (owner-approved). Owner principle: no one-off rules. Every
  encounter difference is a data dial on a rule instance. Delete special-case code; don't wrap it.
- Base `codex/peer-benchmark`. Risk tier: standard.
- Owned:
  - `scripts/warband_combat_rules.gd`, `scripts/snare_pressure_rules.gd`, `scripts/snare_room_rules.gd`;
  - `scripts/enemy_mechanics/{bramble,icefall,tether,tether_forecast,capacitor,lob,veil,dive}*.gd` (only what this
    brief changes);
  - `data/special_encounters.json`, `data/enemies.json` (only the intents named here), `data/glossary.json`, and its
    approved-copy mirror `spec/peer_benchmark/staged/text/glossary_rewrite.json` (exact texts below only);
  - the icon registry (`scripts/action_icon_library.gd`) and `assets/art/icons/` (the five new files only);
  - grimoire topics, intent badges and pre-battle tags for the retired keywords;
  - `spec/analytics.md` and `spec/icon_identity_policy.md`;
  - tests.
- Not owned: views and HUD (the director's el-04 owns the panel, turn-clock token and previews), cutout rigs.

## Keep
- Only the Anchored status holds a unit against any rule. No wielder immunity and no boss, leader, guardian or
  construct exemption. The Gale Herald is Anchored through its data flag (`"anchored": true`, el-01 repair); any other
  unit that must hold gets the same flag, never a type check.
- Immobile units (the Storm Capacitor) stay put because the forced mover already refuses them.

## Change
1. **Warband orders become rule instances** (design §3 rows): the Slagmaster (Wildfire), the Rime Oracle (Frostbite),
   the Dynamo (Lightning Storm on its discharge), the Thornmother (Upheaval) and the Hollow Prior (Shadowstep; it keeps
   hiding followers beyond 2 tiles). The Stormcaller is already done in el-01.
   - Each order's player-facing text in `data/special_encounters.json` becomes its panel sentence, exactly.
   - Remove the one-off order code these replace: the Dynamo's 2-Charge threshold, the Thornmother's
     Bramble-specific wall, the Rime Oracle's pillar wall, and the Slagmaster's Barrage-only paths (Barrage's two crosses
     stay as authored).
2. **Snare pressures become rule instances** (design §3):
   - earth: Upheaval `exit_lane`, replacing the Rubble lane;
   - fire: Wildfire `away_from_entry`, replacing `fire_rows`, with the same opening Fire on the entry row;
   - ice: Frostbite on the existing threshold Ice;
   - lightning: Lightning Storm on the Thralls' lines (see 3);
   - shadow: Shadowstep, with the existing Umbra rings kept.
   Pressure texts become the panel sentences.
3. **Ordinary enemies use the same pieces** (design §4):
   - Briar Weaver Thornwall marks its line, then raises Outcrops (health 3) on its next turn through the Upheaval
     resolver.
   - Hoarfrost Seer Icefall: marked tiles take the shown damage and become Ice ground.
   - Arc Thrall Tether: Lightning Strikes along the line between two aligned Thralls, with the same partner rule, length
     and damage.
   Intent names and their Time stay the same.
4. **Retire Bramble, Ice Pillar and Tether** as keywords and terrain/action kinds.
   - Covers glossary entries, icons and the icon identity test, grimoire topics, intent badges, pre-battle threat tags,
     tooltips and terrain kinds.
   - Delete the then-dead code, including the Gust Shrike Dive's Ice Pillar handling.
   - Saves: a legacy save holding Bramble or Ice Pillar terrain loads with that terrain removed, at the owned load
     boundary.
   - List any card, relic or skill text that mentions a retired keyword as `TODO_DESIGN_text_<id>`. Don't rewrite it.
5. **Adopt the five rule icons.**
   - Copy `spec/peer_benchmark/staged/element_rules/icons/{wildfire,frostbite,lightning_storm,upheaval,shadowstep}.png`
     to `assets/art/icons/` byte for byte.
   - Register the five rule icon keys.
   - Add glossary entries with exactly these definitions:
     - Wildfire: "On its beat, each Fire tile sets the next tile in the blaze's direction on Fire."
     - Frostbite: "On its beat, an Ice hit strikes everyone standing on Ice, Freezing them."
     - Lightning Storm: "On its beat, lightning strikes every Electrified tile; some storms Chain on."
     - Upheaval: "On its beat, the marked tiles rise as Outcrops, throwing off whoever stands there."
     - Shadowstep: "On its beat, every enemy hidden in the dark Blinks toward you."
     - Gust becomes: "On its beat, the wind Pushes every unit downwind. Anchored units don't move."
   - Mirror every glossary change into `glossary_rewrite.json`: the five new entries and Gust's new text with `name`,
     `definition`, `words` and `aliases`; Bramble, Ice Pillar and Tether as `"deleted": true`. Update the entry count
     that `tests/text_budget_test.py` asserts to the new total.
   - Add a hash test bound to `staged/element_rules/icons/provenance.json`.
6. **Design dial removal:** drop the Wildfire `lasting` dial (Fire ground has no expiry today, so it does nothing).

  `tests/test_test_registration_audit.py` and `tests/text_budget_test.py` (el-01 missed the last three; run them).

  windowed allowlist.
- The encounter golden (`tests/fixtures/encounter_measurement_golden.json`) will change in rooms with a Weaver, Seer or
  Thrall. Re-record it only with a structured diff of the combat snapshots before/after showing that every changed field

- **Measurement (report only; the director decides any numbers):** run the existing spx-01 encounter bot harness for
  the six Warbands and six Snares at tiers 1-3, before (base) and after. Report median turns, HP lost and win rate per
  row against the design bands (specials: 3-6 turns, 4-8 HP lost).
- No full suites; the director runs them at merge.
