## Change
1. **Glossary**: replace names/definitions/aliases in `data/glossary.json` with the final rows; remove `deleted` rows
   (and their dead icon-library labels if nothing references them); add the 6 new text-only entries (`wait`, `turns`,
   `ice_pillar`, `movement`, `item`, `outcrop`). The `chain_discharge` alias moves to `charge`
   (`action_icon_library.gd:439`). Enemy-view definition copies, step-tracker labels (`run_scene.gd:14435-14481`) and
   pre-battle threat tags read glossary names instead of hard-coded words.
2. **Renames** (names only, ids unchanged), at every blast-radius line in the md: Thornwall → Bramble (the Briar Weaver
   intent keeps "Thornwall"), Consume Ground/Surface/"consume" (ground) → Expend (item Consume unchanged), Illuminate →
   Light, Summon Minions → Summon, Kindle Ground → Cinder Marks, The Last Eclipse → Last Eclipse, Character and Loadout →
   Character, Rooted → Immobilize, Truesight, Card Play, Embers, Moltshard, "ground", Stoneskin label fix
   (`run_scene.gd:12631`), Storm Capacitor intent "Discharge" → **Arc Burst** (player-visible lines listed; internal ids
   unchanged), relic Storm Capacitor → **Widegap Cell**, Winter's Spur apostrophe.
3. **Token convention** in relic (and any data-driven) text: `@term(key)` renders the concept's icon + glossary name,
   `@kw(key)` renders the name in keyword style without icon, `@term(key|Form)` / `@kw(key|Form)` render the given
   inflected form; names come from the glossary at render time. Unknown keys fail a test. The rendered words are
   hoverable glossary triggers wherever inline icons already are (ux-03 behaviour).
4. **Relics**: write each active relic's final `name` and `description` (with tokens) into the relic data; retired relics
   unchanged.
5. **Turns**: duration chips that show the Time icon for "turns remaining" use the `turns` glossary entry for their
   tooltip panel (the chip art stays until a Turns icon exists). **Movement**: the movement meter's tooltip uses the
   `movement` entry. **Hollow Gale**: wire Vaeloryx's live Hollow Gale intent to the `gale_force` icon/entry.
6. **Budgets**: a test enforcing the style guide's limits — glossary definitions ≤ 20 words, relic descriptions ≤ 25
   words (tokens count as one word) — and that every token/keyword/icon in card, relic, status and intent text resolves
   to a live glossary entry (the ux-03 coverage test stays green; `TODO_DESIGN_GLOSSARY_CONSUME_PROSE` is resolved by the
   Quarry Winch text and removed).
7. **Pinned text**: update tests that pin the old wording to the new approved wording (no weakened assertions); list
   every test touched.
