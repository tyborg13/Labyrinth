# tt-01 — Short card tooltips (owner request, 2026-10-25)

## Header
- Owner: card tooltips are too wordy and too many. Lantern Shot shows six panels, each a paragraph, covering a large
  part of the screen. Time appears on every card, so its panel is excessive. Each tooltip should be "a single
  straightforward sentence that accurately describes it". Fine rules details belong in the encyclopedia (the Grimoire).
- Director copy, protected, import byte for byte: `spec/peer_benchmark/staged/tt-01/tooltips.json`.
  - `entries`: 108 glossary terms with their new `tooltip` (it replaces `definition` in `data/glossary.json`) and
    their `old` definition.
  - `unchanged_ids`: every `skill_*` entry (skills are rules text) and five battlefield rules. Don't touch them.
  - `panel_rules`: drop `time` from card focus tooltips.
  - `grimoire_rule`: where the cut detail goes.
- Base `codex/peer-benchmark` (integration, green). Risk tier: standard. Owned:
  - `data/glossary.json` and `data/grimoire.json`;
  - the card focus tooltip assembly (`scripts/run_scene.gd` `_show_card_focus_tooltips`, and any other surface that
    adds a leading Time panel to a card: reward, shop, deck viewer, codex; find them);
  - tests that pin glossary text.
  - New headless programs: append them last in `tests/headless_test_programs.json` and add the matching
    `POST_SNARE_PROGRAMS` line.

## Change
1. **Apply the copy.** Every `entries[*].tooltip` becomes that term's glossary definition. Inline `@icon(...)` tokens
   and the glossary's term-matching rules (names, aliases) keep working.
2. **Drop the Time panel from cards.** On every card surface, the tooltip stack no longer adds `time`. Time's glossary
   entry stays for other surfaces (the turn clock, the Grimoire). No other panel changes.
3. **Keep the detail in the Grimoire** (`grimoire_rule`). For each changed term:
   - if the Grimoire's keyword, combat or basics entry for that id lacks the old definition's information, append the
     old definition as a body paragraph;
   - if there is no entry, create a `keywords` entry (title = glossary name, icon = glossary icon,
     body = [old definition]) following the existing schema, unlock/discovery rules and section ordering.

   No rules detail may be lost from the game as a whole. Report the count appended and the count created.
4. **Tests:** update every assertion that pins old glossary text to the new copy. Don't delete assertions; pin the
   new strings. A test that asserts a rules fact now lives in the Grimoire should assert it there.

## Proof

  are tallest (find them), before and after. Report each stack's height in px, before and after. The director
  judges them.
- The UI identity lint, the icon identity policy, the Grimoire tests and the glossary/tooltip tests. Focused only;
  the director runs the full suites at merge.
- List the windowed capture commands.

## Out of scope
- Card rules text, skill texts, battlefield-rule lines, tooltip panel styling, widths or fonts.
