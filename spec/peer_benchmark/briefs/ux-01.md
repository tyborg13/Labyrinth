# ux-01 — Start room goes straight to the map

## Header
- Owner (2026-10-12): "in the starting room, after the emaciated man text, we should go straight to the map rather
  than asking the player to pick doors in the room without indication of where they lead."
- Base: `codex/peer-benchmark` (director gives the commit). Owned files: `scripts/run_scene.gd` (≤ 25 lines; prefer a
  small helper script), `scripts/section_map_panel.gd` (only if needed for initial focus), new
  `tests/suites/start_room_map_suite.gd` + `tests/start_room_map_test.gd`, new `tests/start_room_map_probe.gd`
  (SubViewport capture like `tests/movement_undo_probe.gd`), `spec/section_map.md` (one paragraph).
- Rules: presentation/flow only (no rule changes); Windows typed-array rule; keyboard, mouse and controller paths.

## Change
1. In a section's start room (the room where the Emaciated Man's opening narration plays, every section and the run's
   first room), when that narration/dialogue closes by any path (including after his level-up service), open the
   section map automatically using the existing map open transition, with the map focused on the current room and the
   available next rooms highlighted exactly as the map already highlights travel choices.
2. Choosing an available room on the map travels there through the existing door-travel path (same as clicking the
   matching door today), including its travel animation, saves and analytics.
3. Closing the map (Esc/B/close button) returns to the start room as today; the doors still work, and a hint appears
   above the hand area for the rest of the visit: "Choose your path on the map [M]" (existing hint style; controller
   glyph for the map action on controller).
4. Revisits to the start room (backtracking, if allowed) and rooms other than the start room: unchanged.
5. Controller: the map opens with focus on the first available next room (left-most lane first).

## Proof
- Suite: narration close → map open in the start room (all close paths), not in other rooms; selecting a node travels
  identically to the door path (same resulting state hash); close → hint shown, doors still work; save/load in the
  start room after narration keeps the map behaviour sensible (map not re-opened on load unless narration replays).
- Windowed probe captures: narration visible; map auto-opened with choices; after selecting a room (travel started).
  Inspection fixture: a fresh run at the first start room before narration.
- Keep green: full suite, section map v2, movement undo.
