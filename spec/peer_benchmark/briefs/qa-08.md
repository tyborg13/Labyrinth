## Change
1. **Root cause first.**
   - Bisect when `skill_progression_analytics_test.gd` started failing: run it on the commits that touched run
     persistence or analytics on this branch's history since master `816f5e68a`.
   - State whether production behaviour is wrong (a real bug: fix it with a regression) or the test's fixture is
     stale (update the fixture to the current intended flow without weakening what it asserts).
   - Report the evidence.
2. **Audit every test script that nothing runs.** List every `tests/**/*_test.gd`, `*_suite.gd` and `*_probe.gd` and
   classify each:
   - run by the full suite;
   - a windowed probe (by design, outside the suite);
   - orphaned.

   Run each orphaned headless test once and report pass/fail.
3. **Wire the orphans in.** Every passing orphaned headless test joins the full suite: as a program sub-suite if it
   needs its own process, otherwise in-process.
   - Each failing orphan gets a root cause like (1). Small fixes go in this unit. Anything larger goes in the result
     as a list with evidence; do not wire a failing test in silently.
   - Add a guard test that fails when a headless `*_test.gd` exists that the suite does not run, with an explicit
     allowlist for windowed probes.
4. Keep the added full-suite runtime small: report the seconds added. qa-07's parallel runner will absorb it if it
   has landed.
