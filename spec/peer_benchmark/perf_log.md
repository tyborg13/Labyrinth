# Performance log

Invisible performance fixes merged on the director's review (owner rule, decisions 2026-11-04). One line each: what got faster, before → after, commit on `codex/release`. Owner-approved perf units from before the rule are listed for context.

**Standing goal:** the game runs smoothly on the Steam Deck (1280x800, Zen 2 CPU, RDNA 2 GPU, Vulkan).

## Before the rule (owner approved in the inbox)
- perf-15: walking through a door hitches much less: worst door frame 275 → ~90 ms headless (ff9a2be22).
- perf-16: New Run and Continue get you playing faster (6925730ee).
- perf-17: an enemy's first appearance doesn't hitch; cold rig construction moved off the critical frame (11ac26d45).
- perf-18: the worst recurring in-fight spike removed (a48d91a7f).
- perf-19: reward and HUD refreshes keep their controls (c44a4db49).

## Since the rule
- **perf-20** (2026-11-04, 648ead8e4): aiming a card at guardians and dragons stops hitching. Their pattern planning scored facing-independent shapes four times and rebuilt the same sweep footprints for every candidate route; now once, shared within one plan. Per authored plan 193.6 → 20.9 ms; four-enemy targeting p95 33.5 → 9.9 ms, frames over 33 ms 36 → 6; hover p95 11.2 → 7.0 ms (headless, this Mac). Enemy plans, tie-breaks, saves, RNG and preview draw commands identical; Codex review: no findings.
- **perf-23** (2026-11-04, 857e58010): New Run and Continue load faster. Cel-look and imported textures load on worker groups sized to the CPU, published in order on the main thread. On the slow-core proxy: New Run 12.8 → 11.4 s, Continue 12.9 → 10.8 s; main-thread CPU during those loads 3.5 → 2.1 s and 2.9 → 1.6 s. All 3,351 touched textures pixel-identical; Codex review: no findings.
- **perf-27** (2026-11-04, e9d254038): Warband fights redraw their board overlay with less CPU. The captain's command glow was rebuilt every frame though it never changes between moves; its draw commands are now cached and replayed in place, and Icefall marks are gathered once per draw. Idle overlay CPU 257 → 132 µs per frame at 1280x800 (265 → 149 at 1080p); board CPU in those fights about −10% at 1280x800. 960 per-frame command comparisons identical.
- **perf-29** (2026-11-04): the board's HUD layer (health shades, intent medallions, circles) submits 12-17% fewer draw calls per frame. Consecutive untextured geometry goes out as one cached triangle array instead of many polygons, in the same paint order. Native Vulkan with 4x MSAA: HUD draws fight idle 121 → 107, hovered attack 170 → 151, Warband 143 → 123, guardian 82 → 68; 0 changed pixels in all four states.
- **perf-28** (2026-11-04): the HUD's soft shades draw in a handful of calls instead of hundreds. The HUD-seat shade was 136 polygons, now one batch (every combat frame, 135 fewer draws); the action caption shade was 289 polygons, now 17 row batches. Native Vulkan with 4x MSAA: fight idle 803 → 668 draws, hand hover 1001 → 866, card drag 839 → 704, enemy attack 731 → 324. Seat shade pixel-identical; the caption shade differs at 19 edge pixels by at most 2/255 alpha (renderer draw grouping), not perceptible.
- **perf-32** (2026-11-04, 8269bed8f): board layers skip redraws whose output can't change: empty retained layers stay untouched, and the effects/overlay canvases redraw only when what they read changes. Board draw CPU per frame (headless, 1280x800): card drag -17%, enemy attack -8%, walking -3%, idle flat. 248,040 command comparisons and 1,920 native Vulkan pixel checks: 0 mismatches.
- **perf-33** (2026-11-04, 39ab7dbe9): health bars and button ornament sheen draw from retained exact triangle batches. Health bar draws 5.1 -> 3.4 per bar, ornaments 15.5 -> 14.6; steady bar CPU 5 -> 2 us (6 HP) and 21 -> 3.5 us (240 HP). Native Vulkan 4x MSAA: 0 changed pixels in 238 cases.
- **perf-31** (2026-11-04, 012311998): preview lookups (card forecasts, threat previews, enemy definitions) cost less on a cache hit. Definition catalogs are shared snapshots instead of deep copies, and repeated forecasts get targeted keys; full input validation and capacity stay. Memo field reads 58-65% cheaper; Godot static-memory high-water 1.56 -> 1.51 GB; whole-run frames over 33 ms 7,690 -> 7,167 (over 16.7 ms flat). 1,134,241 memo results identical.
- **perf-34** (2026-11-04, 505fb05de): enemy turn planning prunes routes it can't choose, compares heap entries more cheaply, and stops repeating copies and per-plan queries. Intent assignment -7.8% per call, standard planning -12.1% (interleaved fight medians -15% and -28%). 13,653 assignments, five final states and 8,022 analytics payloads identical. Worst frames on the slow-core proxy didn't consistently improve.
- **perf-35** (2026-11-04, eef12aacc): the board keeps each layer's static drawing and redraws only the animated part on the clock (idle HUD was 99% static but rebuilt 30 times a second). Native board CPU per frame at 1280x800: fight idle 2.93 -> 1.74 ms, card hover -39%, drag -37%, enemy attack -35%, Warband -39%, dragon -31%, guardian -14%, walking -3%. 577k command checks and 128 native Vulkan pixel checks: 0 mismatches.
