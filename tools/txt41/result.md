# txt-41 verification

The inventories cover 44 creature pages and 137 moves in the Grimoire, Known Moves, and combat intent fixtures. String changes occur on 73 moves. The txt-38 audit model found 34 remaining False claims, down from 100, with 0 new False claims. All 105 added claims audited True. Thirteen edited rows still carry earlier False claims listed below. The card widget exports are byte-identical across 309 catalog IDs, including catalog, hand, and legacy hover data.

The Grimoire used txt-38's process-local txt-36 override. The supplemental inventory collected the Known Moves controls and combat-intent token and hover data for all 137 moves. Combat fixtures use a standard empty arena and the catalog action data with per-enemy preparation from the shared test fixture. The engine witness also checks held marks on separately committed intents. The baseline audit counted both of Kindle Ground's equal-damage chips as area hits. The after audit follows their separate resolver paths.
