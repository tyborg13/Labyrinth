The code and focused Godot checks establish runtime behavior; the audit script verifies the exact inventory and report rows.

- **False** marks a claim contradicted by a supported runtime case. **Incomplete** marks an accurate core claim with a material eligibility, timing, targeting, or outcome detail missing. **True** marks a claim that holds in its displayed context.
- A line is an authored description or rule body, including fixed fragments that form one body. A shared source has one row even when multiple views reuse it. Distinct authored sources are listed separately. Runtime values are shown with their authored placeholders. Escaped `\n` marks a line break, and `@…` tokens preserve the source markup.
- Word counts treat a substitution as one value and count markup by its concept or visible label. Formatting syntax is ignored when looking for caveats. Separate headings, numeric badges, and unrelated blocks in a composite tooltip are excluded from the sentence check. Embedded title text is retained in the exact template and counted when the source stores it in the same string.
- Scope includes combat and map HUD, pre-battle inspection, shared glossary definitions, Grimoire navigation summaries and search guidance, skills and equipped relic rules, and legacy tooltip branches identified in code. Excludes card rules text, Grimoire article bodies, and retired relic descriptions routed to replacements by [GameData](../../scripts/game_data.gd#L199). No battlefield-rule sentence, Grimoire section summary, or authored enemy JSON entry was flagged. Enemy intent prose comes from GDScript presentation paths. The source manifest records the selected literals and the fixed branches assembled for this revision.
