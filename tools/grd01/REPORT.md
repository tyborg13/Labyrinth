# Ground effects survey

Release baseline `e683b998883057ee756117fd6c8a4a3cdc43d91d` on `codex/grd-01`. Fire, Ice, Electrified and Rubble are the four persistent surfaces. The headless timing matrix has 20 cases across both sizes. Native draw-call counts and gallery images are pending the commands below.

## 1. Inventory

`BoardSurfaceRules.place()` accepts the three `ELEMENTAL_KINDS` plus Rubble on a passable tile without live terrain. Lightning and Charge normalize to Electrified, and Earth normalizes to Rubble. One elemental field and a separate Rubble flag can occupy the same tile. The string values under `surface` in the shipped data are `fire`, `ice`, `electrified` and `rubble`. The glossary has an entry for each. Water is listed in the pixel feedback ramp map and has no placement rule. Air triggers displacement in the trap path and has no persistent surface. Stone Outcrop uses the terrain path. [Placement rules](../../scripts/board_surface_rules.gd) · [Card data](../../data/cards.json) · [Enemy data](../../data/enemies.json) · [Glossary](../../data/glossary.json) · [Feedback ramp mapping](../../data/vfx_pixel_style.json)

The native surface nodes belong to each tile's scene-body canvas. They draw behind that tile's props and units, including an actor on the surface. Tile depth still applies across tiles, so a nearer tile's material can cover part of a unit on a farther tile. Each tile seeds its own local stamps by coordinates, without a same-kind seam join or explicit tile-diamond clipping. At the board edge, the same footprint and rise are used, with later props and renderer clipping applying as usual. Continuous surface redraws are visibility-gated. In Umbra, hidden tiles suppress their surface nodes and surface feedback, and the fog canvas separately draws dark tile fills and edge billows. A material under a hidden tile can therefore be present in state and absent from the image. Tile visibility exceptions still use the production board predicate. [Surface draw and visibility paths](../../scripts/combat_board_view.gd) · [Shared surface painters](../../scripts/board_surface_presentation.gd)

Generated cel look is an asset-load choice. The current manifest excludes the Stone and Iskaldra floor variants used for these fixtures. Biome floor artwork and the board's lighting profile still change between the two rooms. Cel-enabled authored assets are resolved by the regular loaders. None of the four persistent materials goes through the cel filter because their textures and geometry are made in code. All four use the same tile depth and Umbra visibility rules described above. ## 2. Cost baseline

Board-only workload on this Mac with Godot 4.6.1. All cases use the same 9×9 stone grid, no actors, clear visibility, and normal motion. The cases contain 0 tiles, 1 of each kind in turn, 25 of each kind in turn, and a 32-tile mixed case with eight of each kind. Each case owns a fresh board, with 60 warmup frames and 180 sampled frames from the existing dense surface probe. The census settings reused from perf-107/116 are serial background QoS, unit time scale, uncapped scheduling, native VSync off and edge smoothing off. This matrix sets cel to `all` as in the later perf-116 harness and supplies a fixed 60 FPS delta so the board's 30 Hz redraw gate has the same number of opportunities across cases. The production material clock still reads wall time. Reported timing is elapsed time inside the CPU-side callbacks on this host, and phase, machine load and instrumentation overhead can affect the results. ## 4. Pixel FX pipeline and cost

The vfx-01 design brief is in `spec/peer_benchmark/briefs/vfx-01.md` in this checkout. The current renderer computes `grid = max(1, round(2 × backing_height / 1080))`. At 1920×1080, cells are 2×2 physical pixels and full coverage would be 960×540 cells. At 1280×800, cells are 1×1 physical pixels with no resolution reduction. A run of consecutive submissions on the same canvas with the same element shares a transparent, non-MSAA SubViewport. The target is the union of conservative command bounds, snapped to the screen-cell grid, padded by a cell and clipped to the backing viewport. A nearest-filtered sprite composites each run back into its owning floor, behind-unit or front-unit pass. Source transforms and Bayer phase are kept in screen-cell coordinates. [Design brief](../../spec/peer_benchmark/briefs/vfx-01.md) · [Layer implementation](../../scripts/pixel_fx_layer.gd)

The quantizer unpremultiplies RGB and maps Rec.601 luminance to the closest entry in the five-color element ramp. Current live data uses an alpha floor of 0.30 and a bias of 0.12. A texel at or above the floor is opaque only above its screen-anchored 4×4 Bayer threshold plus bias. Line effects use an optional second cropped target with GPU rasterized one-cell cores and wider dithered halos. Cores at or above the floor are opaque, and disappear below the floor. The shipping quantizer and line shaders both composite with normal blending. [Style data](../../data/vfx_pixel_style.json) · [Color and alpha shader](../../shaders/pixel_fx_quantize.gdshader) · [Line shader](../../shaders/pixel_fx_lines.gdshader) · [Line canvas](../../scripts/pixel_fx_lines.gd)

A used target schedules `UPDATE_ONCE` when its owning canvas submits. It remains a retained composite between updates and is freed when the submission run retires. The layer has no separate update clock. Attacks follow the presenting canvas's authored updates. Persistent Fire, Ice and Electrified currently redraw on the board's nominal 30 Hz gate, and Rubble retains its static paint. The historical vfx-01 Vulkan proof used a +1.0 ms median GPU budget at 1080p. Commit `54454a73d` reported +0.095 ms for the lightning CPU path on unique-progress frames after moving line rasterization to the GPU. The historical attack result is not a surface cost estimate. [Historical proof](../../tests/pixel_fx_proof.md) · [Board redraw gate](../../scripts/combat_board_view.gd)
