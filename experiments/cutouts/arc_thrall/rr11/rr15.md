## 1. Composite ordering evidence

The retained director capture contains 670 native poses. Replaying its isolated
GPU pieces with the old stable `z_index` sort reproduces all 528 composite
failures. Replaying the same pixels in native scene-tree order gives **0**
differences over all 670 poses. This is historical evidence, not a fresh capture.

Front idle 6 differs at these seven coordinates in the 512×512 native frame:
`(271,230), (275,231), (275,233), (276,233), (280,233), (285,233), (286,235)`.
Every pixel is an overlap of `hidden_torso` and `hidden_upper_near`.
The bone loader inserts descendant sprites before ancestor sprites. Both
underlays formerly had depth −1, while the layout array listed the torso
first. Thus the native arm preceded the torso, and the isolated composite
painted the arm over the torso.

`tools/humanoid_cutout/underlays.py` derives that native order and encodes it
as distinct depths below all visible paint. This retains the existing native
priority, makes both paths deterministic, and adds no tolerance.
