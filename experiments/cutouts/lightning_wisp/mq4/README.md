# Lightning Wisp r4 semantic cutout

This case binds the approved `mq4_front`/`mq4_rear` paintings to the r4 maquette.
`arc_left`, `arc_right` and `crown` are painted cloud veins and bind to `core`.
The retained director file is byte-identical to the protected rr-04 source.

See [the shared rr-04 handoff](../../shale_bloomer/mq3/README.md) for acceptance
criteria, changed files, test results, chosen proof defaults, native requirements,
exact capture/MP4 commands and the owner-owned inspection fixture command.

Actual headless matrices, production callback records, gates and verification
results are in `proof/`. Native GPU rest equality, render captures, final density
rest records and the real-time MP4 remain for the design owner.
